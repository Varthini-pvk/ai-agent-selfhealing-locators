## Learned

### AI Architecture Concepts
- Difference between agents and workflows
- Importance of separating tools from orchestration logic
- Why scalable folder structure matters in AI systems

### Prompt Engineering Concepts
- Why prompts should be separated from business logic
- Prompts are reusable and evolve frequently
- Prompt separation improves maintainability and testing

### Structured Outputs
Learned that LLMs can return responses in structured JSON formats instead of free-form text.

Benefits:
- predictable outputs
- easier parsing
- safer automation
- reduced hallucination risk

Use cases:
- classification
- workflows
- automation pipelines
- agent decision making

### Function Calling / Tool Calling
Learned how LLMs can decide when to invoke tools/functions.

Concepts understood:
- model selects appropriate tool
- arguments are generated by the model
- orchestration layer executes tools
- tool results are returned back to model

Potential usage in this project:
- Playwright tool execution
- Git operations
- File updates
- Test reruns
